## 背景与目标

人工智能通识教育是中小学素质教育的重要组成部分，但优质师资供给不足、个性化教学资源匮乏、学生自主学习引导缺失，制约了其在基础教育阶段的普及与深化。

参赛团队需基于大语言模型，设计并实现面向 K12 人工智能通识课程的对话智能体，为学生提供交互式、多模态、个性化的在线学习体验，充当“7×24 小时在线 AI 教师”，助力缓解优质教育资源不均、推动 AI 通识教育普惠化。

智能体需根据学生年龄与年级，自适应调整知识深度和交互方式；支持多模态内容生成与交互，以对话、动画、视频、绘本、编程实践等形式辅助学习编程与人工智能知识，并通过游戏化练习实现知识巩固与即时反馈。

## 答题要求

### 1. 智能体核心能力

- 学生可选择所在学段（小学低年级、小学高年级、初中、高中）或教材。
- 根据选择，自动匹配对应的知识库内容、交互风格和难度梯度。
- 小学低年级可侧重语音对话、绘本故事、简单游戏；高中阶段可侧重编程实践、算法讲解、项目式学习。
- 学生可主动提问，智能体也能主动发起对话，引导学习章节内容。

### 2. 多模态交互与内容生成

以下六种方式至少支持三种：

| 方式 | 要求 |
| --- | --- |
| 对话问答 | 通过自然语言对话解答学生在编程、人工智能等学科领域的疑问。 |
| 多模态教学 | 根据学习主题推荐教学视频、Word 文档、PPT 等学习材料；可调用大模型生成，也可由后台上传现有教学资源。 |
| 动画讲解 | 将排序算法、神经网络原理等抽象概念转化为生动直观的讲解动画。 |
| 绘本生成 | 面向低龄学生，将知识点编排为图文并茂的互动绘本。 |
| 编程环境 | 提供在线编程环境与预置代码框架，支持交互式编写、运行、调试代码。 |
| 游戏化练习 | 讲解知识点后自动生成趣味小测验或小游戏式题目，并支持自动批改与反馈。 |

### 3. 个性化学习路径

记录学生学习历史，根据答题表现和兴趣偏好动态调整后续推荐内容，形成自适应学习闭环。

### 4. 系统部署与集成

提供可运行的系统原型，并说明集成部署方案，例如 API 对接、页面嵌入或其他方式。

### 5. 项目报告

详细项目报告需涵盖系统架构设计、大模型调用策略、多模态生成技术路线、知识库构建方法，以及遇到的难题和解决方案。
